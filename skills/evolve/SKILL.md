# Evolve DT Init

Collect the workflow issue or proposed improvement, the command and version involved,
what happened, and the intended behavior. Remove credentials and private repository
details. Prepare a report for [DT Init issues](https://github.com/Dobeu-tech-eco/dt-init/issues)
and post it only with the user's approval. Save the issue link with the lesson if one is filed.
